# Software Requests and Licensing

## §1 Approved Catalogue
The approved software catalogue at Halcyon Labs India Pvt. Ltd. lists every tool that IT has reviewed for security and licensing. You can self-install approved tools from Software Center without raising a ticket. Typical entries include office productivity suites, browsers, IDEs, diagramming tools, the password vault and the GlobalConnect VPN client.

1. Open Software Center on your laptop.
2. Search for the tool or browse by category.
3. Click Install. Updates are pushed automatically.

If a tool is missing from the list, follow the request process in the next section instead of downloading it from the internet.

## §2 Requesting New Software
To request software that is not in the catalogue, raise a request on ServiceHub under "Software > New Software Request".

- Give the product name, vendor, version, number of users and business justification.
- The security review takes 5 working days, covering data handling, vendor assurance and compatibility.
- The licence cost is charged to the requester's cost centre, so the cost centre owner must approve the request.
- Once approved, IT publishes the package to Software Center or issues the licence key.

Requests that need a procurement contract, such as enterprise subscriptions, may take longer, and IT will inform you of the revised date in the ticket.

## §3 Open-Source Use
For open-source software, a licence check is required before using GPL code in shipped products. Engineers should raise a ServiceHub request for a licence review, and the Legal and Engineering Governance teams then check how the code is linked and distributed.

- Permissive licences such as MIT, BSD and Apache 2.0 are generally allowed, but attribution notices must be kept.
- GPL and AGPL code must not be included in a shipped product until the licence check is complete.
- Record every third-party component in the product's software bill of materials.

Internal tools that are not shipped to customers follow the same process, but usually clear faster.

## §4 Prohibited Software
The following software is prohibited on company devices:

- Cracked, pirated or unlicensed software, including key generators and activation bypass tools.
- Personal cloud-storage sync clients, since they can copy company files to private accounts.
- Peer-to-peer file sharing tools and unapproved remote-access tools.

Endpoint protection reports prohibited software to the Security team, which will ask you to remove it. Repeated violations are handled under the code of conduct. If you need a file-sharing capability, use the approved corporate storage and request additional space through ServiceHub.
